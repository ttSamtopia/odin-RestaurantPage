# Odin Restaurant Page

After a year of learning HTML, CSS, and JavaScript at Malmö University, I've been working through the projects in [The Odin Project](https://www.theodinproject.com/) curriculum.

This is the tenth project - a restaurant page built with HTML, CSS, and JavaScript, using webpack to bundle ES modules and render tabbed pages with DOM manipulation.
